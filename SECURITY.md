# Security Policy

## Reporting security concerns

If you discover a security issue, vulnerability, exposed credential, configuration issue, or other security concern related to Dutiva, please report it privately to Dutiva Canada Inc. through approved business or security contact channels.

Please do not publicly disclose vulnerabilities, credentials, exploits, internal infrastructure details, or sensitive configuration information.

## Repository access

Access to this repository may be limited by role, review scope, integration scope, or internal authorization level.

Unauthorized access, disclosure, copying, redistribution, scraping, or misuse of repository contents is prohibited.

## Third-party dependencies

Third-party libraries and dependencies remain subject to their own licenses and security practices.
